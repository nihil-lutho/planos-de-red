Anatomía de una página HTML5

HTML no es un lenguaje de programación

HTML (HyperText Markup Language) es un lenguaje de marcado: no tiene variables ni lógica, solo describe la estructura del contenido mediante etiquetas. Es un estándar, así que cualquier navegador interpreta las mismas etiquetas de la misma forma. CSS se encarga del diseño y JavaScript de la interactividad.

El esqueleto mínimo

Todo documento tiene la misma estructura: html envuelve todo, head guarda la información del documento y body lo que se ve en el navegador.

<!DOCTYPE html>
<html lang="es">
  <head>
    <meta charset="UTF-8">
    <title>Documento de saludo</title>
  </head>
  <body>
    <h1>Hola mundo</h1>
  </body>
</html>

El archivo se guarda como index.html y se abre con el navegador. Para ver el código de cualquier página se usa Ctrl + U, y para inspeccionarla, Ctrl + Shift + I.

Dar formato al texto

  • <b> pone el texto en negrita.
  • <strong> también lo muestra en negrita, pero además le da importancia semántica.
  • <i> lo pone en itálica.
  • <span> marca un fragmento para darle estilo propio.
  • <br> hace un salto de línea; no necesita etiqueta de cierre.

El problema de las tildes

En el laboratorio, las palabras con tilde salían con caracteres raros. Hay dos soluciones: declarar <meta charset="UTF-8"> dentro del head (la que usa este blog) o escribir entidades HTML como &aacute; para la á o &ntilde; para la ñ. Así se ve una palabra escrita con entidades: Programación en español.

Enlaces e imágenes
